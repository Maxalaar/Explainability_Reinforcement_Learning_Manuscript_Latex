\section{Perspectives}
\label{sec:conclusion_perspectives}

The limitations discussed above open several directions for future research.
This section presents four of them.
Each direction is presented as a research topic in its own right.
We first state the research question and the main scientific challenge it raises.
We then describe the approach we envisage and how this approach could be validated.

\subsection{Automatic Textual Description of Clusters}
\label{subsec:conclusion_perspectives_textual_description}

This direction aims to automatically obtain a reliable textual description of each cluster.
The main challenge is that a cluster often captures a dynamic rather than a static situation.
It must therefore be described from sequences of observations rather than from isolated images.

For each cluster, the video segments formed by consecutive observations belonging to it are first extracted.
Each segment is then described in natural language by a vision-language model.
Finally, the descriptions of all segments of a cluster are synthesized into a single description at the level of the cluster.

The reliability of these descriptions can be assessed through a classification test.
Given a new video segment, not used to produce the descriptions, a model must identify the cluster to which it belongs, using only the textual descriptions of the clusters.
The predicted cluster is then compared with the one assigned by \gls{car}.
If the classification accuracy is high, the textual description faithfully captures what distinguishes the cluster.
This would fully automate the \gls{car} method, from the identification of the clusters to their interpretation.

\subsection{From Latent Similarity to the Strategy of the Agent}
\label{subsec:conclusion_perspectives_strategy}

This direction aims to derive an explanation of the strategy of the agent from the similarity of its \glspl{lr}.
The main challenge is that the clusters only group states that the agent perceives as similar.
They must be turned from a static view of the \gls{ls} into a dynamic view of the behavior of the agent.

Each cluster can be treated as an abstract state.
The transitions observed between clusters during episodes, together with the actions taken in each cluster, then define a simplified \gls{mdp}.
This \gls{mdp} can be represented as a high-level graph.
Its nodes are the concepts identified by \gls{car}, and its edges describe how the agent moves between them.
This graph provides a summary of the interaction between the agent and its environment, and therefore of its strategy.

Such a graph is useful only if it is truly informative for an observer.
An observer given the graph should anticipate or describe the behavior of the agent better than an observer without it.
For example, the observer could be asked to predict the next action of the agent, or the next phase of the game.
This validation relies on the protocols presented in the next direction.

\subsection{Human Evaluation of Explanations}
\label{subsec:conclusion_perspectives_human_evaluation}

This direction aims to determine whether the explanations produced by \gls{car} actually improve the observer's mental model of the agent.
It also aims to determine whether the metrics proposed in this thesis, namely \gls{cu}, \gls{as}, and \gls{acu}, are good indicators of this improvement.
The main challenge is that understanding has no consensual operational definition, which makes it difficult to measure.

Experimental protocols from disciplines such as cognitive science and psychology can be adapted to this setting.
In a forward simulation task, the observer predicts the action of the agent in a given situation.
In a counterfactual task, the observer predicts how the action would change if the situation were modified.
In a failure detection task, the observer identifies the situations in which the agent behaves incorrectly.

A controlled experiment can compare several groups of observers.
One group receives no explanation, one receives the explanations of \gls{car}, and one receives those of an existing method, such as saliency maps.
Statistical tests then determine whether the explanations significantly improve performance on these tasks.
The gains observed can finally be compared with the values of \gls{cu}, \gls{as}, and \gls{acu}.
A strong correlation would confirm that these metrics are relevant indicators of the quality of an explanation.

\subsection{Hypotheses on the Structure of the Latent Space}
\label{subsec:conclusion_perspectives_latent_structure}

\gls{car} assumes that concepts are organized as clusters, whereas the \SuperpositionHypothesisName assumes that they are encoded as directions.
This direction aims to determine which of these hypotheses best describes the \gls{ls} of a \gls{rl} agent.
The main challenge is that the two families of methods do not produce the same kind of object, a partition in one case and a set of directions in the other, which makes them difficult to compare.

The metrics proposed in this thesis can serve as a common framework.
They can be applied to the concepts extracted by methods based on superposition, provided that these concepts are expressed as a partition of the observations.
The modularity of \gls{car} also makes it possible to test other distances and other clustering methods within the same pipeline.

Each hypothesis can then be evaluated on the same agents and the same environments, using the same metrics.
The hypothesis that yields the most universal and the most abstract concepts is the one that best describes the structure of the \gls{ls}.
