\markboth{LLM Use Policy}{LLM Use Policy}

\glsresetall

In the course of this thesis, \glspl{llm} were used as assistance for the following tasks:
\begin{itemize}
\item \textbf{Writing:} translation, wording improvement, and proofreading.
\item \textbf{Software development:} code implementation and review.
\item \textbf{Scientific work:} identification of relevant documents and discussion of approaches. They were not used as autonomous scientific sources.
\end{itemize}

All generated outputs were systematically reviewed by the author.
The author takes full responsibility for the content presented in this thesis.
